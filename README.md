# Elyos Conciergerie · visuels en attente de publication

Dépôt technique : il héberge uniquement les visuels finaux des posts Instagram, Facebook et LinkedIn d'Elyos Conciergerie, le temps que Buffer les publie.
Les fichiers sont supprimés après publication. Rien d'autre ne doit être déposé ici (ni documents, ni données personnelles, ni adresses).
